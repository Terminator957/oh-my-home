# 美味家常 · 家庭晚餐食谱与食材加购

从 claude.ai/design 项目「美味家常小程序设计」落地的可运行实现。零依赖、纯原生 HTML/CSS/JS 单文件应用,直接双击 `index.html` 或用任意静态服务器打开即可。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 落地实现(自包含,无任何运行时依赖) |
| `美味家常 Recipes.dc.html` | 原始设计稿(依赖 dc-runtime,仅作参考) |
| `support.js` | 设计稿的 dc-runtime 运行时(仅供设计稿使用) |

## 功能

- **8 个页面**:首页、搜索、菜谱详情、本周餐单、购物篮、确认订单、订单追踪、我的厨房
- **三种加购模式**(顶部切换):
  - A · 按食材勾选:详情页逐个勾选食材后批量加购
  - B · 整套一键加购:整套食材包按当前份量一键入篮
  - C · 一周餐单合并:把菜排进周一~周日,一键合并去重成一份购物清单
- 份量调节(1–10 人份,价格随份量换算)
- 搜索 + 6 个组合过滤条件(30 分钟内 / 小孩爱吃 / 不辣 / 汤羹 / 有肉 / ¥40 以内)
- 购物篮增减、满 ¥79 免冷链配送费、吸底购物条
- 下单后订单追踪时间轴自动推进(已下单 → 拣货 → 配送中 → 已送达)
- 加购飞入动画、Toast 提示、购物篮图标弹跳

## 运行

直接打开:

```bash
start recipes-app/index.html
```

窄屏(≤430px)下自动切换为全屏手机布局,可直接当移动端页面用。
